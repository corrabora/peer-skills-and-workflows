description: Clarify what a written artifact for people or agents, such as a document, report, plan, instruction set or task brief, must accomplish when unresolved audience, purpose, scope, or intended use would materially change its content. Use before drafting or when revision exposes that ambiguity, including when a writing skill calls for it. Skip when existing context supplies the answers or only routine presentation choices remain.

# Clarify an artifact

Read the request, existing artifact and accessible governing sources to
establish the reader, purpose and constraints. For agent instructions, include
the task and inputs the agent will receive. Keep the brief in working context
unless a requested record needs it.

Resolve discoverable facts yourself and reuse settled answers and existing
authority. Choose ordinary wording and layout directly. If an unavailable
source prevents settling the reader, purpose or scope, report its path through
the task's communication channel. Continue independent authorized work while a
required source or answer is pending. State a low-consequence assumption only
when it affects interpretation. For a consequential choice, the answer decides;
do not choose for the user.

Check each statement in the question, its premise, any recommendation or the
settled brief against its sources, including who acts, the conditions and
descriptive details.

When a material choice about audience, purpose or scope remains unresolved,
ask the user or designated coordinator one question: the smallest that settles
the next choice. Begin the reply with the question. It carries the one source
fact that leaves intent undecided and no other context; for a contradiction,
it names both the request's claim and the governing source's contrary claim.
At most one sentence may follow, recommending one of the choices, with no step
after it. The reply ends after the question and its source premise, or after
that one recommending sentence. The reply is this turn's result, addressed to
the user about their artifact; it mentions no skill, rule or pause.

For example: “Should this seek approval or guide staff? The source still marks
the change as proposed.”

Once intent is settled, begin with the reader, state the purpose and end after
the constraints, in a few complete
sentences drawn from the sources. The brief names the sources the artifact
must be drawn from and states the requirements those sources place on its
content, format or use; it does not say how the brief was found or which file
governs. Ask for nothing and report no absence;
what a later draft will need is not this task's dependency. The reply ends
after the constraints, with no closing remark.
