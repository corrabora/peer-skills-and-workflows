# Askerby Beck gauge network: working files

Volunteers read nine river gauges (W1 to W9) and three rain gauges along
Askerby Beck and send their cards to the records keeper, who keeps the
archive. A coordinator runs the network and chairs its quarterly meeting.
An automated data assistant works in this repository on jobs the
coordinator or the records keeper write for it as briefs under `briefs/`.
Readings live under `archive/<year>/`, working notes under `notes/`, the
assistant's standing instructions under `instructions/`, reference pages
under `references/`, and the help page of the `gaugetool` command under
`tools/`.
