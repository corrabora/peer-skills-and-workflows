# Lowmoor Pottery Cooperative: working files

The cooperative runs a shared studio with one electric kiln and a glaze
room. Members book firings and mix their own glazes. Each year the members
elect a kiln steward and a glaze monitor, and a treasurer keeps the accounts.
The committee meets every second month and files its decisions under
`minutes/`. Pages for members live under `docs/`; working notes live under
`notes/`.
