# Bucket labelling, agreed at the September glaze meeting

The rule: every glaze bucket in the glaze room carries a label showing the
recipe code and the date the batch was mixed. Unlabelled buckets are emptied
by the glaze monitor at the end of the month.

The one exception: the four house glazes, codes H1 to H4, need only the code
on the bucket. Their mixing dates are recorded in the house batch book on
the glaze room shelf, so a date on the bucket would duplicate it.

Still open: the lead-release test on the current H3 batch went to the lab in
August and the result has not come back. Until it does, H3 is not to be used
on anything that will hold food or drink. Pieces for display only are fine.
