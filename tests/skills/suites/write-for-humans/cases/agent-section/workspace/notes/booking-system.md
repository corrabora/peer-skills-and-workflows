# Booking by message, from January

Members can book a firing slot by sending a message to the studio inbox
instead of writing in the diary. The message gives the member's initials,
the firing type (bisque or glaze), the number of shelves and the preferred
week.

An automated booking assistant reads the inbox. It replies to the member
within one day with the slot or with the reason it cannot book one. The kiln
steward can override any booking it makes.

Instructions for the booking assistant, to be pasted into its configuration
by whoever runs it:

- Accept a booking only when the message gives initials, firing type, number
  of shelves and a week.
- Book no more than two shelves per member per week.
- When the diary is full for the requested week, do not offer another week;
  send the request to the kiln steward.
- Reply to the member with the slot or the reason, and nothing else.
