# Network terms

<!-- Copied from the Tool Library Network's shared terms. The network maintains
this wording; do not edit it here. -->

The libraries in the network use these terms in the same sense.

## Inter-library loan

A loan of a tool held by one library to a member of another, arranged between
the two librarians; the lending library's rules apply, and the borrowing
library is responsible for the tool until it is returned to the lending
library.

## Network card

A card issued by any library in the network that identifies its holder as a
member of that library to the others.
