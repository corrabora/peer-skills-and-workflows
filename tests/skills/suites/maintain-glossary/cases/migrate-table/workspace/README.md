# Mill Lane Tool Library

A volunteer-run lending library of hand and power tools. This repository holds
the catalogue, the rules the library runs by, and the working notes of its
groups.

Roles: the librarian keeps the catalogue and this repository; desk volunteers
issue tools and take them back; the repair bench volunteers assess, service and
repair tools; the membership secretary keeps the member list; the committee
decides the rules.

- `catalogue/tools.csv` holds one row per tool.
- `docs/contracts/` holds the rules in force. A rule changes only by a
  committee decision, minuted under `minutes/`.
- `docs/references/` holds documents other bodies maintain, copied here for
  reference.
- `planning/` holds the groups' working notes; nothing in a note is in force
  until the committee accepts it.
- The words used in the rules are defined in [docs/terms.md](docs/terms.md); see
  [loan](docs/terms.md#loan) and [overdue](docs/terms.md#overdue).
- Changes are merged to `main`.
